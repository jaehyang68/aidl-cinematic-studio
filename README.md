# AIDL 시네마틱 제작 스튜디오 2.2 · 공모전 분석

인공지능디지털연구소(AIDL) 대표 최재향 AI강사가 만든 공모전 영상 제작 웹앱입니다.

## 2.2에서 달라진 점
- **AI 활용 허용 여부**를 분석표 맨 위에 크게 표시합니다(허용 / 조건부 허용 / 금지·제한 / 공고에 규정 없음). 원문 근거 문장도 함께 보여 줍니다.
- **링크 읽기**: 서버(`/api/read`)가 공고 페이지를 대신 읽고, '모집 요강·공모 안내' 하위 페이지를 최대 3개까지 함께 가져옵니다. 사이트가 차단하면 그 사실을 알리고 복사·붙여넣기 방법을 안내합니다.
- **키 없는 AI 도우미**: 포스터를 ChatGPT·Gemini 같은 AI 앱에 올려 원문을 받는 지시문을 제공합니다(API 키 불필요).
- 분석표에 **시상·상금 / 발표·시상식 일정 / 문의처 / 주최·주관** 칸을 추가했고, 원문에서 찾지 못한 핵심 항목을 경고합니다.
- 37.6MB 단일 파일 → 약 1.4MB. OCR·PDF 엔진은 사용할 때만 jsDelivr CDN에서 받습니다. 엔진 버전은 원래 내장된 것과 같습니다(tesseract.js-core 7.0.0, tessdata 4.1.0, pdf.js 5.6.205, JSZip 3.10.1, CFB 1.2.2).

## 구조
- `index.html` — 웹앱 전체(브라우저에서 실행, 작업 내용은 사용자 브라우저에 저장)
- `api/read.js` — 링크 읽기용 Vercel 서버 함수(내부망 주소 차단, 5회 이내 리다이렉트)
- `vercel.json` — 함수 실행 시간 등 설정

외부 AI API 키를 쓰지 않습니다. 학생도 이용하는 공개판이라 Gemini API 같은 연령 제한(만 18세 이상) 서비스는 넣지 않았습니다.
