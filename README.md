# AIDL AI 영상 제작 스튜디오 2.7 · 공모전부터 출품까지 원스톱

인공지능디지털연구소(AIDL) 대표 최재향 AI강사가 만든 공모전 영상 제작 웹앱입니다.

## 2.7에서 달라진 점
- **📦 결과 한눈에 보기**: 원스톱이 끝나면 자동으로 열립니다. 작품 정보·기획·시놉시스·캐릭터·Master Visual·시퀀스·캐릭터 시트/Master Visual/시퀀스별 영상/음악/편집 프롬프트를 한곳에 모으고, 블록별 복사·결과 TXT 저장·단계 이동을 지원합니다. 상단 [📦 결과], 각 단계 도구줄, 12단계에서도 열 수 있습니다.
- **비주얼 스타일 10종**(고퀄리티 실사, 2D 클래식 애니메이션, 3D 애니메이션, 수채화, 감성 2D 애니메이션, 클레이 스톱모션, 웹툰, 레트로 필름, 다큐멘터리 핸드헬드, 페이퍼 컷아웃) — 모든 이미지·영상 프롬프트에 반영. 프롬프트에는 상표명 대신 화풍 묘사만 넣습니다.
- **화면 비율 5종**(공고 권장 표시). 직접 고른 비율은 원스톱이 바꾸지 않습니다.
- **제목 추천**: 창의 주제 100개는 손으로 쓴 제목, 그 밖의 주제는 문장을 자르지 않는 규칙으로 추천, 8개씩 더 보기.

## 2.6.1에서 달라진 점
- 주제 제안 반복 오류 수정: 목록 끝에서 처음으로 되감아 앞 주제가 다시 섞이던 문제를 없앴습니다. 버튼을 누를 때마다 겹치지 않는 20개가 나오고, 끝까지 보면 안내 후 처음부터 보여 줍니다.
- 🌟 창의 주제 100개(같은 소재·개념 중복 제거), 💡 아이디어 50개. 창의 목록과 아이디어 목록끼리도 겹치지 않습니다.
- 일반 주제 공모전: 🌟 창의 = 연출 형식 30가지, 💡 아이디어 = 이야기 상황 30가지로 역할을 나눴습니다.

## 2.6에서 달라진 점
- 포스터(OCR)와 홈페이지 글을 합쳐도 **같은 예시 주제가 한 번만** 나옵니다(표현이 조금 달라도 같은 질문은 하나로, OCR 오타보다 홈페이지 표기를 우선).
- **[🌟 대상 노리는 창의 주제 20개]**: 뻔한 소재 대신 시각적 훅·반전·시대성이 있는 주제 50개를 20개씩 제안하고, 각 주제에 심사에서 눈에 띄는 포인트를 한 줄로 붙였습니다.
- 붙여넣기 창에서 **기존 원문(포스터 등)에 추가 후 분석** 가능.

## 2.5에서 달라진 점
- 열 때마다 **빈 화면**으로 시작합니다. 이전 작업은 자동 저장되어 [📂 이어하기]와 [프로젝트] 목록에서 다시 열 수 있습니다.
- 눈에 띄는 **[🔄 새 공모전 시작(초기화)]**, **[📋 공고 텍스트 붙여넣기]**, **[🤖 AI 앱으로 포스터 원문 받기]** 버튼.
- 공고 분석 직후 두 갈래 선택: **[🚀 원스톱]** 12단계 한 번에 / **[✎ 직접입력 또는 선택]** 단계마다 고르며 12단계까지.
- 시놉시스 엔진 개선: 상상 → 계기 → 갈등 → 절정 → 선택 → 관객에게 질문을 돌려주는 엔딩 구조. 학생 공모전이면 학생 주인공을 우선합니다.
- 특정 공모전 전용 테스트 버튼을 없앴습니다.

## 2.4에서 달라진 점
- **12단계 논스톱**: 공모전 분석 후 [🚀 12단계까지 논스톱으로 완성] 한 번으로 주제·아이디어·시놉시스·캐릭터·Master Visual·시퀀스·컷·카메라·효과·영상 도구·음악·점검표까지 채우고, 결과 요약에서 단계별로 고칠 수 있습니다.
- **단계별 자동 채우기**: 02~11 각 화면에 [✨ 이 단계 자동 채우기] [자동 채우고 다음 →] [🚀 여기서 12단계까지 논스톱].
- **나의 생각과 의도 5문항**(주인공·분위기·꼭 넣을 장면·메시지·AI 도구)이 모든 자동 채우기에 반영됩니다. 모두 ‘직접입력 또는 선택’.
- **내 입력 보호**: 직접 쓰거나 고른 칸은 자동 채우기가 바꾸지 않습니다. 빈 칸과 예시·자동 문구만 채웁니다.
- 공모 주제 아이디어 20개씩 더 받기, 시놉시스 후보 3개, 심사에서 점수 받는 포인트·감점 주의 카드.

## 2.2에서 달라진 점
- **AI 활용 허용 여부**를 분석표 맨 위에 크게 표시합니다(허용 / 조건부 허용 / 금지·제한 / 공고에 규정 없음). 원문 근거 문장도 함께 보여 줍니다.
- **링크 읽기**: 서버(`/api/read`)가 공고 페이지를 대신 읽고, '모집 요강·공모 안내' 하위 페이지를 최대 3개까지 함께 가져옵니다. 사이트가 차단하면 그 사실을 알리고 복사·붙여넣기 방법을 안내합니다.
- **키 없는 AI 도우미**: 포스터를 ChatGPT·Gemini 같은 AI 앱에 올려 원문을 받는 지시문을 제공합니다(API 키 불필요).
- 분석표에 **시상·상금 / 발표·시상식 일정 / 문의처 / 주최·주관** 칸을 추가했고, 원문에서 찾지 못한 핵심 항목을 경고합니다.
- 37.6MB 단일 파일 → 약 1.4MB. OCR·PDF 엔진은 사용할 때만 jsDelivr CDN에서 받습니다. 엔진 버전은 원래 내장된 것과 같습니다(tesseract.js-core 7.0.0, tessdata 4.1.0, pdf.js 5.6.205, JSZip 3.10.1, CFB 1.2.2).

## 구조
- `index.html` — 웹앱 전체(브라우저에서 실행, 작업 내용은 사용자 브라우저에 저장)
- `api/read.js` — 링크 읽기용 Vercel 서버 함수(내부망 주소 차단, 5회 이내 리다이렉트)
- `vercel.json` — 함수 실행 시간 등 설정

외부 AI API 키를 쓰지 않습니다. 학생도 이용하는 공개판이라 Gemini API 같은 연령 제한(만 18세 이상) 서비스는 넣지 않았습니다.
